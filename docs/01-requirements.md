# 01 需求说明

## 用户

企业员工：遇到制度/产品问题（报销期限、年假、试用期等），需要可信、可核查的答案。

## 目标

基于内部知识库给出**有依据**的回答：引用文档 ID 与逐字原文；多文档冲突时说明冲突并请求确认；
知识库无答案时明确资料缺口；支持多轮追问。

## 输入

- 问题（含可选对话历史与可访问文档范围）；
- 合成知识库：12 份制度/FAQ，含文档 ID、版本日期、生效日期、部门、适用对象、正文。

## 交付结果

回答、引用（doc_id + 逐字片段 + 支持说明）、资料缺口标记、待确认状态、质量校验结果、任务状态。

## 范围

做的：检索、读原文、冲突比较、用户确认后的按指定制度回答、引用逐字校验、数字支撑校验、多轮上下文。

不做：真实企业知识库接入、权限系统、文档管理后台、发布动作。

## 成功标准

1. 明确答案：引用逐字原文且回答中的数字出现在引文中；
2. 文档冲突：列出双方原文与版本，请求确认，不擅自裁决；
3. 资料外问题：明确说明知识库无相关资料；
4. 改写问题：同义改写仍能检索到正确文档；
5. 上下文追问：第二轮能结合上一轮主题；
6. 工具失败：如实说明无法确认，不猜测；
7. 替换文档内容后，答案与引用随之变化（审核要点）。
